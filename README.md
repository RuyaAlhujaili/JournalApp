## App Name & Purpose

**Journali** is a personal journaling app that helps users capture their thoughts and everyday experiences. Users can write, organize, and revisit their journal entries in a simple dark interface.

## Main Features

- **Create entries:** Write and save journal entries with a title, content, and creation date.
- **Edit entries:** Update existing entries, with a confirmation before discarding unsaved edits.
- **Delete entries:** Swipe to delete an entry and confirm the deletion.
- **Bookmark entries:** Mark favorite entries for easy reference.
- **Search:** Find entries by words in their titles or content.
- **Sort:** View entries newest first or place bookmarked entries first.
- **Persistent storage:** Keep saved entries available between app launches using SwiftData.

## Technologies Used

- **Swift** — application development.
- **SwiftUI** — user interface and navigation.
- **SwiftData** — journal entry storage and retrieval.
- **Observation** — observable view model using `@Observable`.
